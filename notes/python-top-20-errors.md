# Top 20 Python Errors You Must Remember

1. `SyntaxError` — invalid Python syntax
2. `IndentationError` — wrong indentation
3. `TabError` — mixing tabs and spaces
4. `NameError` — variable/function not defined
5. `AttributeError` — object has no such attribute
6. `TypeError` — wrong type used
7. `ValueError` — valid type, invalid value
8. `ZeroDivisionError` — dividing by zero
9. `IndexError` — list index out of range
10. `KeyError` — dictionary key missing
11. `FileNotFoundError` — file not found
12. `PermissionError` — no access rights
13. `ModuleNotFoundError` — package not installed
14. `ImportError` — import failed
15. `OSError` — general operating system/file issue
16. `RuntimeError` — generic runtime problem
17. `RecursionError` — infinite recursion
18. `AssertionError` — assertion failed
19. `EOFError` — unexpected end of input
20. `KeyboardInterrupt` — user pressed Ctrl+C

## Quick meaning
- Syntax = code written wrongly
- Name = missing name
- Type = wrong type
- Value = wrong value
- Index = list index issue
- Key = dict key issue
- File = file problem
- Import = module problem
- Zero division = division by zero
- Runtime = logic issue

## Best memory trick
If an error appears, ask:
- Is it a syntax issue?
- Is it a variable issue?
- Is it a type/value issue?
- Is it a collection issue?
- Is it an I/O or import issue?

This narrows the problem fast.
